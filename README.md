# Frontyard Services (U) Limited

Professional cleaning website for **Frontyard Services (U) Limited** — Uganda.

**Tagline:** Give it a new look  
**Motto:** Quality that cares

## Quick start

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Production build

```bash
npm run build
npm run preview
```

## Pages

| Route | Description |
|-------|-------------|
| `/` | Home — hero, story, services preview, FAQs |
| `/services` | Commercial cleaning, pest control, grounds, sectors |
| `/gallery` | Photo gallery |
| `/testimonials` | Client reviews and partner organisations |
| `/about` | Story, values, leadership, FAQs |
| `/contact` | Quote form and general contact |

## Assets

- **Photos:** `src/assets/`
- **Content:** `src/data/siteData.js`
- **Company profile PDF:** place `Frontyard Services Profile 2026 (3).pdf` in `public/` for download links to work
